# Phantom Browser

Script for Linux enthusiasts who work with multiple fresh distros/USBs and need quick command help from ChatGPT's free demo.

## Why?
When setting up new Linux systems, I need quick command references. [ChatGPT](https://chat.openai.com/)'s demo is perfect but hits limits fast. This script creates fresh browser instances for additional free demo access when working across multiple systems.

## Usage
```bash
./phantom-browser.sh         # Single browser instance
./multiple-phantom-browsers.sh   # Multiple instances
```

## Setup
```bash
chmod +x phantom-browser*.sh
```

Requirements: Debian-based distro with Chrome/Chromium
